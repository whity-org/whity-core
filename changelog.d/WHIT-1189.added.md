- **Rename your workspace from Settings › General, and see your own web address on Branding.** A workspace's owners and admins (`tenants:write`) can now change the workspace name on General, saved with the rest of the form. The rename is audited, and an empty name is refused: `PATCH /api/v1/tenants/{id}` now answers 422 for a `name` that is present but blank, instead of quietly keeping the old one. Branding shows the workspace's own web address, read-only, through the new `GET /api/v1/branding/host` (`settings:read`). It always reads the caller's own workspace and says when the plan doesn't include an own address. Setting the address stays with the system tenant (WHIT-1189).
