- **Plugin SDK 1.165: a package for plugin screens.** Plugin developers get one package, `@whity/plugin-sdk`, with the screen building blocks Whity accepts, a checked way to build them, a client for their plugin's own pages of data, and test helpers. It is checked against the plugin SDK on every change, so the two can't drift apart. It ships on npm with a later release (WHIT-1392).
