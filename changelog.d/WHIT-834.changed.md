- **The JavaScript packages are now `@whity/ui`, `@whity/features`, `@whity/tokens` and `@whity/api-client`, published to public npm.** They were `@whity-org/*` on GitHub Packages, which needs a token even to install a public package; on npmjs.com they install with no `.npmrc` or token. Releases are published from GitHub Actions with npm trusted publishing, so no long-lived npm token exists, and each version carries a provenance statement linking it to the commit that built it. Projects that use the packages must switch their dependencies and imports from `@whity-org/*` to `@whity/*` and can delete the `@whity-org` registry line from `.npmrc` (WHIT-834).
