- Plugins can now keep secrets such as API keys and connection credentials (SDK 1.60). `\Whity\app(PluginSecrets::class)->for($this)` gives a plugin its own store, with `set`, `get` and `delete` per workspace. Values are encrypted with the host key and kept apart by plugin and workspace. They are never read back by settings or the API, the audit trail records only the key, and the store works in routes, MCP tools and jobs (WHIT-838).
