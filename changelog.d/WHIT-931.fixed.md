- **A retried MCP tool call no longer runs twice.** A client can send `_meta["dev.whity/idempotencyKey"]` with `tools/call`: a retry with the same key gets the first result back (or "still running" while it runs), and the same key with other arguments is refused. Without a key, an agent's Ask-first call that matches a proposal still waiting returns that proposal instead of adding a second one to its person's approvals. Keys are kept for 24 hours (#1798).
