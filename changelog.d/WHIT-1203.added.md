- **Each further workspace a person owns can start on a paid plan (WHIT-1203).** Operators set `workspaces.additional_plan` (a plan key) and `workspaces.additional_trial_days` (default 30, 0 = no trial) on the Sign-up tab. A person's first owned workspace still starts on `billing.default_plan`; every further one they create starts a trial of the additional plan, and once an unpaid trial ends the workspace is read-only (`block_writes`) until it is paid: people can still open and read everything, and nothing is deleted. Co-owned workspaces count for each owner; being invited never counts. "Create a workspace" says so before it is made, with the plan's monthly price, in English and Arabic. Empty by default, so self-hosted installs are unchanged. A `trialing` subscription whose end date has passed no longer counts as current.
