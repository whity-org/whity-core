- **The app no longer runs as root.** The web server and every worker run as
  `www-data`; the image's entrypoint hands the storage volume, plugins and
  Caddy's state to `www-data` on the first start (about a second for 20,000
  files) and then drops privileges for good. It still listens on :80, so no
  proxy or URL changes. The compose files drop every capability but the five
  that start needs and forbid privilege gain. `WHITY_RUN_AS_ROOT=1` switches
  back to root if writes fail; see the deployment guide (WHIT-1359, CO-26).
