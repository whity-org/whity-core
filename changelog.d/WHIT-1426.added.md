- **A reference plugin for the customer area.** `plugins/MyCourses` shows a plugin author the whole path: a learner's Courses tab with a count, a "Continue learning" card on their Home and a full-screen lesson player, on routes declared for customers and scoped to each learner's own enrolments, with the isolation test that proves it. It is the starting point for a learning plugin and runs on the development stack only (WHIT-1426).
