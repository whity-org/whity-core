- **Workspace agents and presets.** Admins can now define the workspace's agents: each has a role name, role and instructions in English and Arabic, a tone and language, the toolsets it may use, and the Off, Ask first or Allowed grant a person's use of it starts from. `GET/POST /api/agents`, `GET/PATCH /api/agents/{id}`, `POST /api/agents/{id}/archive` and `/restore`. Five core presets (Finance clerk, HR assistant, Document drafter, Front desk, Billing assistant) are listed at `GET /api/agent-presets`; creating an agent from one copies it, so a later preset version never changes a live agent. A preset or workspace agent may start reads at Allowed but never a write: only the person sets a write to Allowed. A new `agents:manage` permission gates it and goes to every role that may already mint MCP credentials. Agents can't create or edit agents (`agentPolicy: refuse`). People grant these agents for themselves in a following release (migration 180; WHIT-815).
