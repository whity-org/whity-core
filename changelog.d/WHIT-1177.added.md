- The plugin SDK (1.115) adds the dashboard. `PluginDashboardInterface` lets a plugin add setup points to Finish setting up, each opening its own setup step or screen and marked done by its own status route, and dashboard widgets (stat, list, chart, actions) built from blocks, each with a permission, sizes and one data route. `GET /api/me/dashboard` lists what the caller may see, and `PUT /api/me/dashboard/layout` keeps each person's order, hidden items and sizes, home cards included. Migration 303 moves hidden home cards into `dashboard_layout` and drops `home_card_hidden`.
