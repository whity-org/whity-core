- **Plugins and Whity Builder can ship agent presets (SDK 1.61).** The optional `PluginAgentPresetsInterface`, or `agentPresets` in `plugin.json`, offers ready-made agent templates: a persona in English and Arabic, toolsets and where a person's grant starts. `GET /api/agent-presets` now lists core's, code plugins' and the workspace's own plugins' presets, keyed `<plugin toolset root>.<key>`, and `POST /api/agents` can start from any of them. A workspace plugin's presets reach only that workspace. A preset may start a read at Allowed but never a write, and its toolsets must be the plugin's own or core's. A bad preset in a code plugin is dropped with a logged reason; in a manifest it fails validation (WHIT-818).
