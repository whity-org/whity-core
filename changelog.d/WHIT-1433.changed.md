- **A template's plugin is now on only in the workspaces that use it.** Templates whose plugin is off in your workspace still appear when you choose a template, and choosing one turns its plugin on. This needs permission to turn plugins on. A workspace that already uses a template gets that template's plugin turned on automatically, so it keeps its setup, updates and look; other workspaces leave it off. Turning a template's plugin off never deletes what it made (WHIT-1433).
