- **`billing.seller_name`, `billing.seller_address` and `billing.seller_tax_id` are gone; use `company.name`, `company.address` and `company.tax_id`.** For operators: migration 188 moves existing values once, global defaults and workspace overrides alike, and never overwrites a company value already set. A script or API client that writes the old keys now gets a 422 and must use the new ones (WHIT-788).
