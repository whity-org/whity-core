- **Plugin SDK 1.161: the 2.0 names, ready now.** Every contribution point a plugin declares also has the name it keeps in SDK 2.0, under `Whity\Sdk\Contribute\` (for example `Contribute\PluginDashboardInterface`). Both names are the same type, so a plugin can move at its own pace, and the old names keep working. A plugin can also reach contacts, time off, away and bookings through its plugin context (`$ctx->contacts()`, `timeOff()`, `away()`, `bookings()`), which always act in the workspace the request runs in, so it no longer passes a workspace id (WHIT-1387).
