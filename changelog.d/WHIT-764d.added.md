- **Approving a workspace plugin change shows what it does.** When an AI agent (such as Whity Builder) proposes publishing or rolling back a workspace plugin, the proposal now carries its impact plan, so the person approving sees it before deciding. The plan lists each change, the existing records it touches and whether it is safe, needs attention or destructive, in English and Arabic. For a publish, it also shows whether the plugin's own tests pass (WHIT-764).
