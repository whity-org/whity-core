- **Operators can approve a plugin for an existing role (#1907).** Since 0.2.26 a plugin grants its permissions only to roles it created or roles the operator approved, but nothing could record an approval, so roles a plugin made before 0.2.26 were refused on every boot. `whity-cli plugin role-approve <plugin> <role> [--tenant <id>]` (and `POST /api/plugins/{name}/roles/{role}/approve`, operator only, audited as `plugin.role_approve`) approves one role and applies the plugin's own grants at once. The refusal is logged once per role instead of on every boot, and names that command. There is no automatic backfill: each role is approved by a person. See Core-Update.md.
