- **Embedded plugin screens no longer run as the app (WHIT-1217).** The frame for a plugin's `screen: 'embed'` page dropped `allow-same-origin`, which together with `allow-scripts` let the page remove its own sandbox, read the app's page and call the API with the person's session. A framable plugin response is also sent with `sandbox allow-scripts allow-forms` in its Content-Security-Policy, replacing any `sandbox` the plugin wrote, so the page has no origin of its own even when opened in a tab. An embed page still loads with the person's own request; calling the API from it after loading waits for a message bridge. No first-party plugin uses an embed screen (#2140).
