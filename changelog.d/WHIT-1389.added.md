- **Plugin SDK 1.163: more of a plugin in `plugin.json`, checked before you install it.** A plugin's settings, notifications, jobs and their schedules, dashboard, guided setup, contact fields and themes can now be written in its `plugin.json` instead of PHP. `whity-cli plugin validate <folder>` checks the file offline and lists every problem with where it is, theme files included (WHIT-1389).
