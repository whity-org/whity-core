- **MCP splits.** One slice of the server at its own URL, for narrow clients and hard boundaries: `/mcp/documents`, `/mcp/forms`, `/mcp/people` and the other core areas, each plugin at `/mcp/<plugin>`, and composite splits an operator names in `MCP_SPLITS` (`sales=core.forms,acme.*`). A split runs search and call like `/mcp`, and what is outside it doesn't exist there: search can't find it, and calling it is an unknown tool. Each split is its own OAuth resource with its own metadata; a token issued for one split works only there, and a token for `/mcp` works on all of them. `GET /api/mcp/splits` lists the ones you can reach, and the audit trail records the split. The single `/mcp` stays the recommended connection (WHIT-765).
