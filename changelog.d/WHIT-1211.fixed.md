- **An empty or broken database backup no longer passes as a good one.** After
  a reboot a backup could run before PostgreSQL was ready and save a 20-byte
  file with nothing in it, and both "restore the newest backup" and the
  freshness alert trusted it. Now `scripts/backup-db.sh` waits for the database
  and checks each dump (size, archive test, complete dump, enough table data)
  before it counts; `scripts/restore-db.sh` refuses a dump that fails, and with
  no file named restores the newest valid one, saying which newer ones it
  skipped; and the freshness exporter reports `whity_backup_latest_valid` with
  a new `WhityBackupLatestInvalid` alert (#1908, WHIT-1211).
