- **See what a workspace template would add before applying it, and test templates like the real thing.** `POST /api/workspace/templates/{key}/preview` runs the same engine as apply but changes nothing, and lists each item as added, already there, made before, left out or not possible with why. The engine that applies templates now lives in the plugin SDK (1.169), with a test kit for template authors that checks a template is valid, that applying it twice changes nothing, and that an update never deletes, overwrites or brings back what the person changed. Each template run now records the version of every part it applied, ready for update offers (WHIT-1409).
