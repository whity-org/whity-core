- **The release image no longer runs the reference plugins (#1831).** HelloWorld and ExamplePlugin still ship in the image as examples, but the image sets `WHITY_REFERENCE_PLUGINS=off`, so they add no routes, permissions, `hello_viewer` role, scheduled job or migrations to a deployment. Set `WHITY_REFERENCE_PLUGINS=on` to run them; development, CI and e2e keep them on. Rows they already wrote stay. See Plugin-Distribution.md.
