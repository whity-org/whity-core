- **Workspace templates can build on each other, take pieces from other plugins, and offer their updates item by item.** A template can build on another (a Dental template on Clinic), and a plugin can add forms, services, roles and setup steps to another plugin's template. A template plugin can now be just JSON files listed in `plugin.json`. When a template a workspace uses gets a new version, the templates list says what is new. Applying again adds only the new pieces and leaves everything the workspace already has as it is. For each item the template changed, "Use the template's version" updates that one item, without deleting anything and only when the person asks. Plugin SDK 1.170 (WHIT-1413).
