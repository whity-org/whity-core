# Form printout: an ethics application

FP: a long form as a printed record and approval certificate — page 1, long answers, an N/A section, the section filled in, signatures and checklist, the decision.

Example University is fictional. The same layout serves any client: the letterhead, colour and footer marks come from the client's document theme.

Printed pages: A4, 16 mm margins, Noto Sans 9.5 pt body, Readex Pro titles, one print colour (the client's document theme). Pages stay white in dark mode. Decisions FP.1–FP.12 in `00-decision-register.md`; block specs in `DocFormBlocks`; engine work in `handoff/print/FORM-PRINTOUTS.md`.
