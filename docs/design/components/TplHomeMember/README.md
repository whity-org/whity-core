# Home for a member

The same home (H.1) for someone who can see less: Ahmad, staff at the Sweifieh branch. Nothing in it is a separate design; cards simply don't appear without the permission behind them.

- **Nothing waiting** collapses Waiting for you into one line with a success mark, so the page doesn't open on an empty box. It stays first, where decisions will appear (H.2).
- **Your recent documents** stands in the main column when nothing waits: drafts and what the person sent this week, with status.
- **App cards** show only the person's scope: Stock for his branch, his branch's deliveries (H.4).
- **Hidden cards** are listed at the foot with Show, so hiding is never a dead end.
- No Finish setting up and no Agents today: he has no agents and can't change workspace settings.
