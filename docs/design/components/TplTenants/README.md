# Tenants (A40, operators)

The Platform group's workspace list (W.2): logo, name, plan, people, status in words (Active, Trial with days left, Payment overdue, Suspended), since. Searching and paging run on the server (the built page loaded the first 100). A row opens the workspace record (P.2): Overview (people, plan, slug), Plan and billing, Overrides (features turned on or off for this workspace), History. The page and its record say **workspace** in the interface; "tenant" stays in the code.
