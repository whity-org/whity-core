# Mobile: applications

- **What you have to score:** To score, Scored, All, with each applicant's stage and whether their documents are complete.
- **Scoring:** each criterion as five 56 × 48 buttons, a note, and **Save my score**; others' scores show after.
- **Applicant: where it is,** in the tenant's brand: the stages as steps (done, now, next) and what's still needed, with a button to add it.
- **Applicant: adding a document:** a photo or PDF; the Screening assistant says at once whether it's readable and the name matches, before it's sent.
