# Audit log (A44)

What happened, in sentences grouped by day (W.4): who (a person in bold, or an agent's actor chip "for Amro"), what, to whom, and a muted line with how (from where, on what device, allowed by its settings, waiting somewhere). Items still waiting have Open. Filters: Who, Agent, Area, When (a set filter tints). **Export** (CSV). Never "#id" as the actor.

**Show technical details** adds the event code, ids, IP address and raw details to each line.

Arabic: سجل التدقيق · تصدير · من · الوكيل · المجال · متى · اليوم · أمس.
