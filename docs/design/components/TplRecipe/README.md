# Recipe

An item you make (IN.1): a **recipe** (bill of materials) for one batch, what it costs, and its **batches**.

- **Recipe:** each ingredient with quantity, cost per unit and cost; batch cost and **cost per unit** worked out from current stock costs. Edit changes it from the next batch on; past batches keep the recipe they were made with.
- **Sells for, margin, made this month.**
- **Batches:** a number (B-1108), when it was made, how many, the **expiry date** (made date + shelf life), and where they are now. Making a batch takes the ingredients out of stock, adds the product, and prints labels with the batch number and expiry. A batch near its date is amber and listed first.
- Selling and moving stock follow first expiring, first out; a recall can be traced from a batch to every place and order it went.
