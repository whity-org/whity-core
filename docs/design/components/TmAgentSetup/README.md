# Mobile: setting up an agent

Agents can be created and changed on the phone (X.1), in four steps:

1. **Start from a preset** (Billing, Stock, Notes, Front desk, Bookkeeping) or from scratch.
2. **Instructions** in the person's own words, a name, and **who it works for**.
3. **What it may do:** each action Off, Ask first or Allowed, never more than the person it works for (a line says so when an action can't be given).
4. **Where it works:** channels (WhatsApp), chats and boards; a summary of the agent in one sentence; **Create the agent**.

The web has the same steps with the full instructions editor (`TplAgentInstructions`, `TplAgentScope`).
