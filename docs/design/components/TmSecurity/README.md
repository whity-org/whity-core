# Mobile: sign-in and security

**Status on top** (M.42): a ring with how many of four protections are in place (a strong password, this phone as a passkey, recovery codes saved, an authenticator app), "Well protected", and the missing one as a button (**Add**). Then:

- **Ways to sign in:** password (when it was changed), passkeys, Google or Apple, authenticator app.
- **Devices:** every device signed in, where and when, **This phone** marked, a **Sign out** on each, and **Sign out all other devices** in the bottom bar (red). Coming back needs the password and this phone's approval (M.32).
- **Recent sign-ins:** by day, each with the device, place, and how it was approved; a blocked attempt is shown as a warning at the top with what happened next.
- **App lock** (M.8): Face ID to open, how soon to ask again (default 5 minutes), the 6-digit app PIN, hiding Whity's screen in the app switcher; tier-3 decisions always ask for Face ID and that can't be turned off.
