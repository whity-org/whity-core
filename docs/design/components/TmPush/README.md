# Mobile: push notifications

Notifications **only open the app** (M.44): there are no Approve or Decline buttons on a notification, so every decision is made with its facts in front of the person, after Face ID.

- **Lock screen:** each notification names the workspace ("Whity · Example Bakery", M.17) and says what's asked in plain words. **Amounts are hidden** on the lock screen by default (Preferences › Notifications). Several from one agent group into a stack ("3 more waiting"). Sign-in approvals come first and are never grouped.
- **Press and hold** shows the full text and one action, **Open in Whity**.
- **Opening** asks for Face ID, then lands straight on that decision (not on Home), with a close button and, after deciding, the next one waiting.
- **Inside the app**, a new decision slides in as a banner at the top for 4 seconds with **View**; swipe it up to dismiss. It never covers the tab bar or the bottom action bar.
- Sign-in approvals open the number-matching sheet (`TmCreatorCustomer`, M.32). A daily summary of agent work, if turned on, opens the Agents tab's Today view.
