# Mobile in Arabic

Fully mirrored (M.45): the tab bar runs right to left (Home on the right), back arrows and chevrons point the other way, lists, headers and sheets mirror, and swipe directions flip (swipe left to mark read, right to archive).

One exception, for one-handed use: **the main button follows the hand setting (M.46), not the reading direction.** With the right hand (the default), **Approve** stays on the right in Arabic too, under the thumb; with the left hand it moves left in both languages. Swipe to approve follows the hand the same way.

- Text is Noto Sans Arabic at the same sizes; line height a little taller (1.45 for titles).
- **Numbers stay Western digits** and amounts, codes and invoice numbers stay left to right in mono (JOD 312.000, INV-1042), inside right-to-left sentences.
- Names of companies stay as written (Example Café); the product name is always "Whity" in Latin letters.
- Dates use the Levantine month names (تشرين الثاني) by default; the installation can choose Gregorian month names.
