# Plans and pricing (A42, operators)

Plans as cards side by side (name, price per month, three key inclusions, how many workspaces are on it, Edit plan); tabs for **Compare features** (a feature-by-plan table with ticks) and **Affiliates**. Prices are entered with `MoneyInput` in normal units with the currency's decimals (JOD 49.000), never minor units (the built page asked for 4900). Retiring a price is tier 2 and names the workspaces on it, with **Move workspaces** to another price. Plan names and prices stay `[plan name]` and `[price]` in designs.
