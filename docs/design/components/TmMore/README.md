# Mobile: More

The **More tab** (M.41): the person's card on top (picture, name, role and workspace), the workspace switcher, then grouped 56px rows:

- **My work:** Documents (with how many to sign), Forms and my requests, Decided by me.
- **Manage Example Bakery** (shown only to people with admin rights, M.40): People, Agents, Billing, Activity and security, Workspace settings.
- **You:** Preferences, Sign-in and security (with its "3 of 4" status), then Help and about (below the fold).

**Your workspaces** opens as a sheet: each workspace in its own logo and colour with the role and installation; the current one is ticked; **Add a workspace** connects another (M.14). Switching re-themes the app (M.17).

**Profile:** the picture (`TmOnboardPicture`), name, email, mobile, job title; the Whity ID and the workspaces it reaches; **Sign out of this phone**.

**Help and about:** the help assistant (an agent that answers questions about Whity), replay the tour, the story again, the help centre; contact the workspace's admin; report a problem; version, installation, privacy, terms and licences.
