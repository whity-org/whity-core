# Settings: Single sign-on (A52)

Each provider is a card: icon, name, how it appears on the sign-in page and which email domains it accepts, On/Off, Edit. The address to give the provider sits in a grey box with Copy. **Add a sign-in provider** offers Google, Microsoft and Other (OpenID); client ids and secrets are fields in the edit drawer, with the secret never shown again after saving. Deleting a provider is tier 2 and names how many people sign in with it.
