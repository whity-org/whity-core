# Approval gating (A16, A48)

One page with three tabs (Sign-ups, Password resets, Two-step resets), each shown only to people with its permission.

- **Rows:** the person (name, email), what they asked and why, **when** (missing in the built app), and the decision.
- **Confirmation (P.4):** rejecting a sign-up is tier 2; approving a password reset or a two-step reset is tier 3 (type the email), so Approve reads "Approve…". The two-step tab leads with a warning to check identity first.
- **Paging** for long lists; empty: "No requests waiting".
- The sidebar item needs the permission, not the role named admin.
