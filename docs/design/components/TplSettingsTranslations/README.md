# Settings: Translations (A45)

Coverage per language as tiles (the number of strings still missing), then a table of wording: English, Arabic (or **Add Arabic**), and where it appears in words. "Only missing Arabic" is on by default. Editing is in place with Save and Cancel; the system default and a workspace override are shown as "Whity's wording" and "Yours". Keys and domains appear only with Show technical details. Badges are 13px (the built page used 10px).

Languages (A45, operators) is a Platform page: code, name, direction and on/off per language.
