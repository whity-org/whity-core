# Form responses

The Responses tab of a form (F.4).

- **Summary:** one card per choice question (a donut, up to five slices and Other), responses per week, and where responses are in their routing. Text and file questions aren't summarised.
- **Table:** the identifying answer (company and contact for this form; the person for internal forms), a key answer, Submitted, and **Routing** (With Awss Haddad, Approved, Rejected, Returned). A row opens the response as a record (P.2): the answers, the attached files, and the routing timeline with decisions.
- **Header actions:** Copy link (public forms), ⋯ Export responses (CSV), Close the form (tier 1, Reopen).
- **States:** "No responses yet" with Copy link or Share; responses hidden from people without `forms:read` on that form.
