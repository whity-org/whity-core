# Agents (A20, new)

Whity's own agents (AI.1). Tabs: **My agents** (everyone) and **Everyone's agents** (admins).

- **Table:** Agent (robot avatar, name, its job in a line), Works for (the person; an agent never has more access than them), On its own (how many actions are Allowed and how many Ask first), Last active, Status (Working, Paused). A row opens the agent's page.
- **New agent** (main) opens the preset gallery (AI.2).
- **Row menu:** Open, Pause or Resume (tier 1), Delete (tier 2: its history stays in Agent activity).
- Empty: "No agents yet. Start from a ready-made agent; it asks you before doing anything that matters."
