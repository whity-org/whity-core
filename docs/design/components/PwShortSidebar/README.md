# Sidebar on short screens

PW.10 (WHIT-1006, WHIT-827). On a short window the sidebar's ends stay put: the workspace switcher at the top, Settings and the account row at the bottom. Only the links scroll, with a fade at the ends. The account row opens the account menu upward. Built from the `wy-shell__*` parts plus `.pw-desk*` in `bundle.css`.
