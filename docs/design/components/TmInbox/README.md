# Mobile inbox

The Inbox tab (M.43) has three tabs at the top and the **search bar at the bottom**, above the tab bar (M.7).

- **Waiting for me:** everything that needs the person's decision, oldest first: agent proposals (dashed robot tile, "for you"), documents to sign, leave, people asking to join. Amount in mono and age at the end. Tapping opens the full decision (`TmHome`). Swipes follow the person's setting (M.6): by default right marks read, left archives.
- **Mentions:** who mentioned them, where, the comment itself and when. Tapping opens the document at that comment with the reply box under the thumb.
- **Updates:** what happened, grouped by day: decisions they made (with **Undo** and the time left while it lasts), signatures, agent work, payments.
- **Filters** open as a bottom sheet: what (payments, documents, leave, people, orders), from (anyone, people, agents), how long it has waited, order (oldest first, newest first, biggest amount); **Clear** and **Show 2** at the bottom. Chips are 44px tall.
