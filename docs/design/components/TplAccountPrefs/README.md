# Account: Preferences (U04)

A person's own settings (W.3), reached from their name at the foot of the sidebar. Tabs: **Profile** (name, editable; photo; email addresses with Set as primary), **Sign-in and security** (`TplAccountSecurity`), **Sessions and devices** (where they're signed in, Sign out, Sign out everywhere else), **Preferences**:

- **Language and theme**, the controls that used to sit in the sidebar footer.
- **Text size:** Standard (15px, A.1) or Larger (17px, every size one step up), saved on the account.
- **Show technical details** (A.3): codes, ids and error details beside the plain words.

Changes here apply at once (no save bar), with a toast.
