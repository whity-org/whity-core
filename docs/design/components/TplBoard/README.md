# Board

A board is **a view of tasks** (T.2): each board is a Taskaat project, its columns are task statuses, and the same task shows in lists, calendars and boards.

- Header: the board's name, who's on it, **Board**, **List** or **Calendar**, Board settings, New task.
- Columns: **To do**, **Doing**, **Awaiting review**, **Done** (renamable, more can be added). **Awaiting review is the gate** (amber): an agent's task arrives here with "Evidence ready" and leaves when a person accepts it or sends it back. People's tasks with a check land here too.
- Cards: an optional status, the title, a label, check progress (bars, green when met), the due date and the assignee (agents with the robot).
- **Dragging:** the card lifts onto the plane (the offset shadow, tilted 2°) and a dashed slot shows where it will land. A card can't be dragged into Done past the gate; dropping it there asks for review first. Keyboard: pick up with Space, move with the arrows, drop with Space.
- Done shows **Verified** or **Done, unverified**.
