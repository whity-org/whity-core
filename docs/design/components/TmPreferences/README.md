# Mobile: preferences

Everything set in onboarding can be changed here, with the same **real UI in motion** (M.23).

- **Preferences:** Display (text size, theme, language), Using Whity (what Home shows, swipes, the Create sheet's tiles), Feel (haptics, sounds, reduce motion), Data (download files on Wi-Fi only).
- **Display:** a live card that grows as the slider moves; bold text; follow the phone's text size; theme (light, dark, match phone); language (English, العربية).
- **Swipes** (M.6, M.9): a looping real row; pick what a right and a left swipe do (mark read, archive, snooze, delete); **Swipe right to approve** is off by default and only ever approves ordinary items. Delete, if chosen, is heavy (M.24).
- **Notifications,** per workspace: decisions, documents to sign, mentions, a daily agent summary; **Sign-in approvals** are always on (they protect the account); quiet hours, which sign-in approvals still pass; what the lock screen shows (default **Hide amounts**).
