# Mobile: the form builder

Forms are built on the phone as a list (FL.2, X.1):

- **Questions as a list:** each with its kind, whether it's required and anything special (filled from the receipt); drag to reorder, **+** between questions; the flow that runs when it's sent. **Question** and **Publish** in the bottom bar.
- **Adding a question:** large tiles for the kinds (short or long text, choose one or several, amount, date, photo, file, a person), or ask an agent to suggest questions.
- **A question's settings:** wording, choices, required, show only if (a condition in a sentence), and the Arabic wording.
- **Publishing and sharing:** who can fill it in, a QR code and link, WhatsApp, and adding it to everyone's Create sheet.
