# Reports

**Basic reports** (roadmap N7), read-only views of the accounts (MO.1), always up to date.

- **Profit and loss** for a period against the previous one: sales, costs grouped plainly (ingredients, packaging, salaries, rent, fuel and delivery, waste at cost), gross and net profit, and the change in percent (good green, bad red).
- **Who owes us** by how late (not due, 1–30, 31–60, 60+ days), and **whom we owe** the same way.
- **Balance sheet**, **stock value by place**, **sales tax by period**.
- Every report downloads as a PDF (Whity Render) and can be emailed monthly. A report builder is long term (L10).
