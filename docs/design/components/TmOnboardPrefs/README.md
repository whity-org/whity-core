# Mobile onboarding: preferences and tour

Preferences one per screen (after language, which comes first and is detected from the phone), each with **real UI in motion** showing what the choice will mean (M.23):

- **Text size:** a live card grows and shrinks as the person drags the slider; it follows the phone's setting until changed.
- **Gestures** (M.6, M.9): a real row loops through the swipe so people see it before choosing **Safe swipes only** (default) or **Swipe to approve too**. The caption says tier-3 items stay put and ask.
- **Notifications:** a real notification slides down; switches for decisions, sign-in approvals, a daily agent summary, mentions. **Allow notifications** then asks the phone's permission.
- Theme and Face ID follow the same pattern.

**Guided tour** (M.28) on the person's own Home: a spotlight on one thing at a time (Waiting for you, Create, Inbox, Agents), a tip card above the thumb with Next and Skip tour, "2 of 4". The tour can be replayed from More › Help.
