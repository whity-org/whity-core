# Approvals: the list

Reviewing **one at a time** stays the default (`TplAgentApprovals`); a **List** view adds bulk approval for **ordinary tier-1 items only** (AQ.1).

- Each row: the proposal and the agent ("for you"), the amount, the **kind** (Ordinary, Check first, Needs verifying with a lock), how long it has waited.
- Ticking selects tier-1 rows only; tier-2 and tier-3 rows show **Open** and can't be ticked. The bulk bar shows the count and what it adds up to, with **Approve 4** and Decline.
- Bulk approval gives each item its own Undo, listed together in the toast.
