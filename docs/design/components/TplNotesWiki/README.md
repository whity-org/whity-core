# Notes and wiki

Uses the Whity table (the built page was a plain list). Two buttons in the header, both visible (A.2): New note (outline) and New wiki page (main). A switch for All, Wiki and My notes. Columns: Page (icon, title, kind), Written by, Shared with (in words), Changed. A row opens the page in the editor, continuous view (section 18).

Empty: "No pages yet. Write the first wiki page for your team." Readers without permission to write see no New buttons and "No pages shared with you yet".
