# Mobile: meetings

- **Today:** everyday and formal meetings (blue edge), **Join** for video, and what needs you (minutes to approve). Bodies lists the committees.
- **Running a formal meeting:** the current agenda item with a timer against its time, **Rec** at the top while recording (everyone told), attendance and quorum, the agenda with what's done, and three large tiles to add a **Note**, a **Resolution** (with a vote) or an **Action item**. **Next item** in the bottom bar; **Pause** stops the recording.
- **Approving minutes:** the agent's dashed draft with resolutions and votes; **Edit** or **Approve minutes**.
- **Action items to tasks:** each with an owner and due date; an agent's gets a done-when check drafted from the discussion. **Approve and create 3 tasks** makes them in Taskaat.
