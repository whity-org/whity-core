# Document routing (A32, circulation)

Circulation is the **Routing** tab of the document record (D.3); the old address redirects here.

- **The route:** its stages top to bottom, like the flow editor (D.2). Each stage shows who it reached (people, not "Profile #id"), the rule (any one decides, everyone, a count), and its outcome with time. Done stages are green with a check, the current stage is in the main colour, the next ones grey. A document on several routes shows one card per route.
- **Your decision** (only when it's waiting for you): a note seen by everyone on the route, then **Approve** (the main button), Reject, Return to the sender, and Forward to someone else. One sentence says what happens next.
- People who can send documents see **Send on a route** instead: choose a route template or step by step.
- Rejecting and returning are tier 1 (Undo for 10 seconds, before the next person is notified).

Arabic card: `TplDocRoutingAr`.
