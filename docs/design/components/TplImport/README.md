# Import

**Import from a spreadsheet** (roadmap N3), for contacts, items, opening stock and opening balances; the column matcher is the one label sheets already use (section 18).

1. **Choose a file:** Excel or CSV; Whity finds the header row.
2. **Match columns:** each column with an example value and where it goes in Whity, including the workspace's own fields; Whity suggests matches by name and content, fixes what it can (adds +962 to mobile numbers) and says so; anything doubtful is amber; empty columns are skipped.
3. **Check — what will happen:** new, updated (matched by tax number, mobile or a chosen key), skipped with reasons (downloadable), new tags created. **Nothing changes until you import.**
4. **Import**, with Undo for the whole import for 24 hours.
