# What AI can do (A22, was MCP tools)

Every action AI can take (AI.4), in plain words: Action, Area (with the plugin that adds it), **Agents** (Can do it, Proposes and a person approves, Suggests only, Never) and **If it goes wrong** (how long Undo lasts, or that it can't be undone). Filters for Area and Can; search.

**Show technical details** (A.3) adds the tool name, toolset, how apps discover it (standard, every action, search only) and token counts, the content of the built MCP tools page, plus the always-on switch for plugin tools that ask for it. Number formatting follows the person's language.
