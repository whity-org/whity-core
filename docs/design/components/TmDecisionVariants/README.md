# Mobile: decision variants

- **Edit before approving:** the agent's draft opens in an editable box (here in Arabic, right-to-left); "You added 4 words. The assistant learns from your changes."; **Approve with changes**.
- **Decline, with a reason:** a sheet with optional reasons as chips, a note, and **Tell the Billing assistant** (on by default) so it does better; then **Decline**.
- **Tier 3, after Face ID** (M.21): the card opens only after Face ID; a green line says it's verified for the next 2 minutes. The facts include who checked it. A warning says there's no Undo. **Approve** carries a lock.
- **Decided by me:** today, this week or everything, approved in green and declined in red with the reason; **Undo** with the minutes left where it still works; search at the bottom.
