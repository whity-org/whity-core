# Tasks

The Tasks page (Work › Tasks). **Tasks run on Taskaat** (T.3): projects, sections, tasks, checks, evidence and decisions live in Taskaat; this page reads and writes them with Whity's people, agents, permissions and look. "Open in Taskaat" opens the same task there.

- **Tabs:** My tasks, Assigned by me, Agents' tasks, All. Filters for board, due and who; List, Board (the board view, `TplBoard`) or Calendar.
- **Groups:** Overdue (red), Today, This week, Later, Done today. Each row: a round tick, the title and who it's with ("Stock assistant · for Ahmad Khalil"), a status where it matters, the board as a coloured chip, the assignee and the due date.
- **Agents finish their own work** (T.1): a task given to an agent runs within the agent's scope; actions its permissions allow happen, and "Ask first" actions become proposals in Approvals. When it's done, the agent submits **evidence** against the check.
- **Done when** (T.4): agents' tasks must have one, written before the work starts; people may add one. The panel shows it in a blue box, then the evidence item by item, then the **gate**: "Awaiting your review", **Send back** or **Accept as done**.
- **States:** Working (an agent on it), check progress (2 of 3 met), Awaiting your review (a dashed amber tick), Done and verified (green), **Done, unverified** (closed without passing evidence; it stays marked, as in Taskaat).
- **Decisions** keep the reasons behind choices, so later sessions and people can see why. The footer names the Taskaat task and when it last synced.
