# Users (A10)

The list pattern (P.1): page header with the main action, tabs, a filter bar, then the table.

- **Header:** Invite people is the main button. ⋯ holds Add without inviting (sets a password; for workspaces without email) and Export to CSV.
- **Tabs:** People and Invitations (email, role, sent by, expires; Resend, Revoke).
- **Filter bar:** search (name or email), filter buttons for Role, Unit and Two-step (a set filter turns tinted and names its value), and Active / Deactivated / All.
- **Table:** Person (avatar, name, email), Role, Unit, Two-step, Last active, Status. Names, never ids: the inventory's Tenant ID column is gone (a person's workspaces are on their page). Selecting rows shows the bulk bar: Change role, Require two-step.
- **Row click** opens the person's page (P.1). **Row menu:** Open, Send reset link, Deactivate (tier 1, Undo), Delete (tier 2).
- **States:** first-time empty "No one here yet" with Invite people; filtered empty; loading; error; access denied for people without permission to view users.
