# Adding an agent to a chat

Agents join chats the way people do, but with three things said out loud (CH.2):

- **What it can read:** from now on (the default), the last 7 days, or everything. Choosing more than "from now on" is shown to everyone in the chat.
- **Who it works for here:** its proposals go to that person for approval, and its actions are done as their delegate.
- **What it may do here:** per action, Off, Ask first or Allowed, never more than the person it works for can do (as in `TplAgentScope`).

A system line in the chat records it; anyone can see the agent's settings beside the chat; people with the right can remove it.
