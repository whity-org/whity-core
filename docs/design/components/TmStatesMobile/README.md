# Mobile: app states

- **Offline:** a banner under the status bar ("You're offline. You can keep deciding; it sends when you're back."). Tier-1 and tier-2 decisions still work and wait in **Waiting to send**; anything that needs Face ID and the server (signing, tier 3) waits until online. When the connection returns, a toast says "2 decisions sent".
- **Installation not answering:** names the address and the workspace, says the others still work, **Try again**, a way to switch, and the installation's status page.
- **Updating** (maintenance): the loose sheet hovers over the platform (the "not yet" motion), when it'll be back, and **Tell me when it's back**.
- **All caught up:** the sheet set down on its platform, "All caught up", what the agents did today, **See what they did**.

The same pattern covers an app update that's required (one button to the store), a session that ended (sign in again with Face ID), and no permission for a page (who to ask).
