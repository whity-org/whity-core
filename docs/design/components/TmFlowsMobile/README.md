# Mobile: flows

Built on the phone as **a list of steps in sentences** (FL.2), no canvas.

- **Flows:** each with how often it ran and how many are running; **Describe a new flow** lets an agent draft one from words.
- **A flow as steps:** the trigger (blue), conditions (amber), people deciding, agents acting (dashed), waits, top to bottom; the highlighted words are what can change; **+** between any two steps adds one. Branches show as an indented pair under the condition when opened. **Try it** and **Publish** in the bottom bar.
- **Changing a step:** a sheet with the sentence at the top, who decides (a person, a role, the branch manager, an agent), how long they have, and what happens if no one answers.
- **Following a run:** every step done with who and when, where it's waiting now, and what's next; stop the run, or mark a wait as done by hand.
