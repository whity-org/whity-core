# Mobile: subscriptions

- **Plans at a glance** (the tenant): active subscribers, monthly income, each tier with its count, and who's past due.
- **A subscriber:** what failed and what's next (retry 2 of 3, a WhatsApp sent), the plan, next box, payment method; retry now, change, pause; Message on WhatsApp.
- **Customer: choosing a box,** in the tenant's brand: tiers as large choices with the price in mono; skip or pause any time.
- **Customer: their box:** when the next one comes; **Skip next week**, change, pause, payment, cancel. Cancelling asks once if they'd rather pause.
