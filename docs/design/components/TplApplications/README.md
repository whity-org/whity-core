# Applications

Requests people send for something — a job, supplier status, a partnership, a permit, a grant (X.4) — reviewed **in stages with a scoring panel** (AA.1).

- **Application types** each have a public form, stages and scoring criteria. Tabs switch between types with how many are open.
- **Stages** as a pipeline with counts (Received, Screening, Review, Trial shift, Decision); choosing one filters the table.
- The table: applicant, **average score** (mono), whether the **documents** are complete (checked by the Screening assistant first), who has scored, and when they applied. Filters include **Scored by me: not yet**.
- Moving people between stages works in bulk; each move can send the applicant a message from the stage's template.
