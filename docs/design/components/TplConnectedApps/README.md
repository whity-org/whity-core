# Connected AI apps (A20, was AI principals)

Outside AI apps signed in to Whity (AI.1). Columns: App (its initial tile and name), For (the person), May do (in words: "Everything Amro can do, asking first for changes", "Read only", or the areas), Last used, Expires. A row opens the app's page with **What it may do** (the ScopeGrant list, `TplAgentScope`), Renew and Disconnect (tier 2: "Claude will stop working for Amro right away").

**Connect an AI app** (main) opens the three-step wizard (`TplConnectWizard`). Kind ("ai-agent") and user numbers, shown raw in the built page, appear only with Show technical details (A.3), as does the credential id.
