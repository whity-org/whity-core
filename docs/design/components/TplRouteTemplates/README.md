# Route templates (A32)

Each route described in one sentence ("Branch manager, then the owner over JOD 1,000, then Finance"), with its number of stages and how often it's used. New route (main) asks for a name and opens the flow editor. Row menu: Open, Duplicate, Delete (tier 2; documents already on the route finish it). Empty: "No routes yet. Make one so documents go to the right people."

Arabic: قوالب المسارات · مسار جديد · المراحل · استُخدم.
