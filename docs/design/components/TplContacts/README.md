# Contacts

**Customers and suppliers as one record** (roadmap N1), used by invoices, purchase orders, appointments, subscriptions and chats.

- **Tabs:** Everyone, Customers, Suppliers. Filters for tags, balance (owes us, we owe) and branch. Import and New contact.
- **List:** name with customer or supplier, tags, and the balance in mono (late amounts red).
- **A contact's page** (beside the list, or full page on narrow screens): WhatsApp, Call, New invoice; money (owes us, this year); details (contact person, mobile, tax number for JoFotara, how they pay); **Your fields** — the workspace's custom fields (N2) — with a link to add one; and what happened recently, including agents' proposals.
- A contact can be both a customer and a supplier.
