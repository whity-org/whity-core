# Agent instructions

The Instructions tab: a large plain-text box at 15px, written as to a new colleague (no prompt syntax), with who changed it last. Beside it: **What it may read** (pages and templates it uses for reference, beyond the records its permissions allow) and **How it writes** (tone, language). Edits use the save bar (P.3). Instructions never widen what the agent may do; the What it may do tab decides that.
