# Mobile: search

- **Search everything:** from Home (pull down) or any list's bottom search with the scope set to **Everything**. The field stays at the bottom, above the keyboard (M.7). Scope chips (people, documents, invoices, settings), recent searches, and questions to try that go to an agent.
- **Results, grouped** by kind (customers, invoices, documents, people, settings pages), the matching words highlighted, amounts in mono.
- **Nothing found** says where it looked and offers to **ask an agent** to find it.
- **An agent asks first:** when a request is unclear, the agent asks one question with tappable answers (48px chips) before preparing anything; what it prepares arrives as a dashed proposal with **Review it**, never sent without approval.
