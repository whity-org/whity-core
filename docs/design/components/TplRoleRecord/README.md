# Role record (A12)

The record pattern (P.2) on its Access tab.

- **Header:** role icon, name, facts (people, permissions "26 of 61", where it applies, last change and who), ⋯ (Duplicate, Delete role).
- **Access tab:** permissions as a grid of areas by actions (See, Create, Change, Delete, Approve) grouped by area (People, Documents, Apps from plugins), with the permission codes shown only when Show technical details is on (A.3). "–" where an action doesn't exist. A search and "Only allowed" switch replace Expand all / Select all. A changed row gets a primary bar at its start; the save bar names the change (P.3).
- **Who holds this role:** people with their unit, and "Give this role to someone".
- **Agents:** how agents of these people relate to the role (they never exceed it).
- **Built-in roles** (Owner, Admin) open read-only with the read-only alert (V.2) and "Duplicate to change".

Arabic: ما يمكن لهذا الدور فعله · عرض · إنشاء · تعديل · حذف · موافقة · من يحمل هذا الدور.
