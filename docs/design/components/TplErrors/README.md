# Errors (A44, operators)

Groups of the same error, each first in plain words ("Route Maps didn't load"), where (area and workspace), how often, last seen, and **Resolved** / Ignore as buttons. Tabs: Not resolved, Resolved, Ignored (each item there has Reopen or Stop ignoring). **Show technical details** adds the error type, message, file and line, environment, first seen and the stack trace. The page uses the standard header (the built page had its own).
