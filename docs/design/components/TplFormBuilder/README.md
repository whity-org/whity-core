# Form builder

A form's record page (P.2): header, then tabs **Questions**, **Responses**, **Settings** (F.4). The Questions tab is the builder (F.1).

- **Header:** form icon, title, Draft / Open / Closed badge, facts (who can fill it, where it's routed, last change), **Preview** and **Publish** (main). Publishing a changed open form asks whether existing drafts keep the old questions.
- **Canvas:** the form as people will see it, on the grey ground: title and description, sections (a bar in the main colour), questions as cards with their number, title, required star, help, type label and a preview of the answer. Click a question to select it: primary ring, and a small toolbar (move, duplicate, delete). **Add question** between cards opens the types: Short text, Long text, Number, Date, Choose one, Choose several, Checkbox, File, Person, Unit. Questions with conditions show an "Only if …" pill.
- **Settings panel:** the selected question's type, wording, help, options (drag to reorder, Other option), Required, **Show this question** (Always, Only if …), and **Save the answer to** a field on a record. With nothing selected, it shows the form's settings.
- Native dropdowns are replaced by Whity selects throughout (the inventory found them on every form).
