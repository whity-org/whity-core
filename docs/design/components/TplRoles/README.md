# Roles (A12)

- **Header:** New role (main). It opens the new role's page with Overview filled from a short dialog (name, description, start from: blank or a copy of a role).
- **Table:** Role (name, Built in badge with a lock, description), People (count, "No one"), Permissions ("24 of 61"). Row click opens the role page (P.1).
- **Row menu:** Open, Duplicate, Delete (tier 2, naming how many people hold it). Built-in roles show Duplicate only; the inventory's "disabled with a hint" becomes not offered.
- The page describes how roles combine, once, in the header.

Arabic: الأدوار · دور جديد · مدمج · الأشخاص · الصلاحيات · لا أحد.
