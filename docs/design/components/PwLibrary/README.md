# Phone web: library

Part of **the web app on a phone** (WHIT-1006, register PW.1–PW.9). The web app under 640px wide, in the browser and installed (PWA). It reuses the phone app's parts (`.wm-*` in `bundle.css`, section 26) so both look the same; the new parts are `.pw-*`.

Web app on a phone: the document library with folders, collections, search, grid view, Arabic (PW.5)

Every screen has English and Arabic (RTL), light and dark. Targets are 44px or more, text 15px or more.
