# Plugin store (A41)

Where a workspace finds plugins (S.1): `/admin/plugins/store`, the Store tab beside Installed.

- **Search and categories:** one search box (names, publishers, what it adds) and a single category switch: All, Finance, Sales, People, Operations, Documents, Agents.
- **Made by Whity:** first-party apps and services (Front Office, Whity Render, Whity ID) as wide cards with a blueprint strip, because they're how Whity works. Billed on the Whity invoice like every paid plugin (S.2).
- **Sections:** Most used (by workspaces like this one, with "See all"), and Tools for your agents. New and Updated sections follow the same pattern.
- **Plugin tile:** the publisher's logo, the name ("<Job> for Whity" for third parties), the publisher and its trust mark (By Whity, Verified, or Sandboxed), one line, what it adds (Screens, Document blocks, Agent tools on the tint, Fields, Connects out), how many workspaces use it, and the price (`[price]` until decided, or Free). No stars (S.4). Hover lifts the tile onto its plane, like any clickable card.
