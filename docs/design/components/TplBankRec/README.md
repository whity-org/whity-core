- Left, each bank line as the statement says it (amount, date, the bank's text); right, what it matches in Whity: an invoice paid, a bill, an expense claim, a transfer, or an account.
- **=** exact matches (same amount and reference) can be confirmed together. **?** the Bookkeeping assistant's suggestions, dashed, with why ("same name, half the order total"). **!** nothing matches, amber: choose an account or attach a bill.
