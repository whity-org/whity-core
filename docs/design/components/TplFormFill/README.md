# Fill in a form

Filling in a form while signed in (`/forms/[id]`).

- **Steps (F.2):** a form with sections shows them as steps with the Stepper; short forms are one page with Submit. Back and Continue at the foot; the last step is Review, with Submit.
- **Prefilled:** what the workspace already knows (name, unit, leave balance) shows as a summary from the profile, not as fields to retype.
- **Draft:** saved as people go ("Draft saved at 10:42"), on the server, so it continues on another device; the forms list shows it under Continue where you left off. A restored draft says so, with Start over.
- **Where it goes:** the description names who receives it; the decision arrives in the Inbox.
- **States:** not available, not accepting responses ("Closed on 31 October"), submitted ("Sent to Emad Nasser" with View your submission). All text is translatable (the built form was hardcoded English).
