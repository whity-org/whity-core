# Mobile: tasks

Tasks on Taskaat (T.3), reached from More › My work (and Home's "Waiting for you" when a gate needs you).

- **My tasks:** Mine, By me, Agents; grouped Overdue, Today, This week. A dashed amber tick and **Review** mark a gate. Search at the bottom with **+** beside it.
- **Reviewing evidence:** the agent and who it works for, the title, **Done when** in the blue box, the evidence item by item, and **Send back** or **Accept as done** in the bottom bar.
- **A task for an agent:** what needs doing, who does it (people or agents as chips), **Done when** (required for agents, T.4), due and board; the button names the agent.
- **Done, unverified:** a task closed without the evidence its check asks for stays marked; **Add a photo** or **Reopen**.
