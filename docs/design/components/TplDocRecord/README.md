# Document record (A30)

One issued document (D.3). The record pattern (P.2) with four tabs: **Document**, **Routing**, **History**, **Verification**.

- **Header:** title, the state for this person ("Waiting for your decision"), facts (raised by, issued, current stage, verification), **Download PDF** and **Print** as buttons (A.2), ⋯ with Add to collection and Withdraw this document (tier 2).
- **Document tab:** the rendered PDF (`DocPreview`, zoom, the current version), and beside it **About this document** (template, the key fields, where it was raised from, unit) and **Versions** (current and superseded, each openable).
- **History:** what happened, in sentences, with people and agents.
- **Verification:** the QR code's state, Issue a new code and Withdraw this code (tier 2), and scans in words ("Checked from Amman, today 09:14"). The SHA-256 checksum appears only with Show technical details (A.3).
- The record now links to Routing (the inventory found no link from the record to circulation).

Arabic card: `TplDocRoutingAr`.
