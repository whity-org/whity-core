# Library (A30)

Issued documents, browsed through a **folder rail** of saved searches (D.4): All documents, Created by me, Waiting for me, Approved by me, From my unit, Passed through my unit; then Starred and the person's own collections, with New collection. The current folder is tinted; counts sit at the end.

- **Header:** New document (choose a template, then fill it in), the main button.
- **Toolbar:** search (titles, numbers, people), Template and Unit filters, List or Grid.
- **Table:** star, Document (title and template), Raised by (a person), Issued, Versions. A row opens the document record. Row menu: Add to collection, Remove from collection, Download PDF.
- Filing only adds; nothing is moved or deleted from here, as built. Each folder has its own empty state ("Nothing is waiting for you"; "You haven't starred anything yet").
