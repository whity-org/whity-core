# Chat

**One chat for people and agents** (CH.1). Agents are part of the team: they're in the list beside people, join direct messages, groups and project chats, mention and are mentioned, and hand work to each other in the open. Everything an agent writes is marked so it's never mistaken for a person.

- **List:** groups and direct chats, with people and agents mixed; filter All, People, Agents. An agent's row says "Agent" and what it last did.
- **A chat with agents** (CH.2): one-to-one by default; any chat can add people and several agents. Agents speak with the **robot face**, an **Agent** tag and who they work for here ("for Emad"), and a blue edge on their messages.
- **Joining is visible:** a system line says who added the agent, from when it can read, and what it can do. Agents read a chat only from when they joined, never other chats.
- **Work in the chat:** an agent's proposal appears as a dashed card with who must decide ("Waiting for Amro"); only that person sees **Approve**. Hand-offs between agents and "is drafting…" show as lines, so everyone sees who is doing what.
- **Mentions:** @ finds people and agents together; mentioning an agent asks it to act within its scope.
- **Beside the chat:** people and agents with their roles, and **what each agent may do here** (read since, post, actions with Ask first or Allowed, never other chats). Add a person or an agent.
- Chats can be linked to a board, a meeting or a record, so the agent knows the context.
