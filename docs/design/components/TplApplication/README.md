# An application

One application under review (AA.1).

- **Header:** the applicant, the type, when they applied, the stage, and the actions: **Ask for more** (a message with a request, by email or WhatsApp), **Decline** (with a reason and a kind message from the template), **Move to** the next stage.
- **Answers** from the application form.
- **Documents:** the **Screening assistant** checks them against what the type needs (present, readable, the name matches) and asks the applicant for anything missing, with reminders; missing items are dashed amber.
- **Your score:** each criterion 1 to 5 as large buttons, a note per criterion, and a note for the team. **Others' scores stay hidden until you've saved yours**, so reviewers aren't swayed. The average appears in the list once two reviewers have scored.
- Every move, score and message is in the application's history; decisions can be routed for approval like any other.
