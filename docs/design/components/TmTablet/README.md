# Mobile on a tablet

Two panes on tablets (M.47), the same app and code:

- From **744 points** wide, lists and their detail show side by side (list 400 points). Below that (split screen, Slide Over) the phone layout returns.
- A **side rail** replaces the tab bar: workspace logo, Create, Home, Inbox, Agents, More. It mirrors to the right in Arabic.
- Bottom sheets open as **centred dialogs or popovers**; the bottom action bar becomes buttons at the bottom right of the detail pane, main button last.
- Text and targets keep the phone sizes (17px, 48px).
