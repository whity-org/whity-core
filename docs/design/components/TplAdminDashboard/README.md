# Admin dashboard

The platform cards system-tenant operators see on their home (H.1, section 20), below Waiting for you: tenants, agent actions, plugin health, the overdue-backup warning, the tenant table and plugin states. Built from `AppShell`, `PageHeader`, `Card`, `Alert`, `DataTable`, `PluginCard`. Numbers and tenant names are placeholders; the Whity lockup shows because this is Whity's own console, not a tenant's.
