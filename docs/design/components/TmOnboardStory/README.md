# Mobile onboarding: the story

The first thing a new person sees (M.28: Story → Whity ID → workspace → preferences → tour). Three short screens make the brand make sense (M.23), each a Lottie animation built from the mark, a title and one sentence. **Skip** at the top end; Next in the thumb zone.

1. **Your company, on one platform:** the blue platform rises, a white sheet lands on it with the mark's offset. The sheet is the customer's brand; the platform is Whity.
2. **Agents do the work:** a loose, dashed sheet drifts in and hovers above the platform: an agent's proposal, not yet real. It loops gently until the next screen.
3. **You approve, it happens:** a thumb taps, the sheet sets down onto the platform and turns solid, and Undo appears. This is the same motion the app plays every time someone approves (`TmMotion`), so the story teaches the interaction.

Motion rules (M.19): the sheet moves on one easing (ease-out, 200 to 400 ms), never bounces, and only moves when it means something: drifting is "not yet", setting down is "done". Keyframes are noted under each animation for the Lottie files. With reduce motion on (M.25), each animation shows its last frame.

**Create your Whity ID** (M.26, M.27): Continue with Apple, Continue with Google, or email and password; "I already have a Whity ID" to sign in.
