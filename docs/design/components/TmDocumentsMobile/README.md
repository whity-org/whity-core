# Mobile: documents

- **Documents:** To sign (the default when there are any), Recent and All; rows with who sent it and when it's due; search at the bottom.
- **Reading one:** the page itself, scrollable and pinch-zoomable, with the signature box marked; the facts that matter (from, supplier, amount in mono, routing step); **Comment**, **Return** and **Sign** in the bottom bar.
- **Routing:** the steps top to bottom: done (green tick, who, when, their comment), now (you), next. Return explains what happens.
- **Signing:** the saved signature (or draw a new one with a finger), one sentence on what signing means and what's recorded, **Sign with Face ID**. Signing is always Face ID, whatever the swipe settings.

On the web: the document designer, templates and route templates (A31 to A33).
