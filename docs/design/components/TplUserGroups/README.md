# User groups (A11)

Groups are rules, not saved lists; the page says so in its header. Groups are small things, so a row opens a **drawer** (P.1).

- **Table:** Group, Who's in it (the rule in a sentence), Now (current count), Used in (routes, forms, templates).
- **Drawer:** name, description, the rule as conditions (field, is, value; include units below; Add a condition; conditions in one group are AND, separate groups OR), then **In it right now** with the people, recalculated as the rule changes. A note says what changing the rule affects and that past sends keep their recipients. Footer: Delete group (tier 2), Cancel, Save.

Arabic: مجموعات المستخدمين · مجموعة جديدة · من فيها · الآن · مستخدمة في · أضف شرطاً · فيها الآن.
