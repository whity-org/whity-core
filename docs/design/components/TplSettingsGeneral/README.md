# Settings: General (A50)

The settings pattern (W.1): page header with breadcrumb, a grouped **sub-nav** (Workspace: General, Branding; Sign-in and security: Security, Single sign-on, Sign-up; Email: Email domains; Data: Tags, Translations; Advanced: Error tracking), then the page. Pages a person can't open aren't listed. A page added by the server lands under Advanced.

- **Workspace:** name, support email, time zone and language. A value that follows the platform default says so ("Same as the platform default"); clearing a field returns to the default.
- **Company details:** legal name, tax number (with why it matters), address, phone, documents email.
- Whity selects replace the native time-zone dropdown. Edits use the save bar (P.3).
