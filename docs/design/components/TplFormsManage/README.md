# Form builder list

The list pattern for people with `forms:manage`. New form (main) starts a blank form or a copy. Columns: Form (title, description), Status (Draft, Open, Closed), Who can fill it (in words: a group, everyone, anyone with the link), Responses, Changed. A row opens the form's page on Questions, or on Responses once it has any. Row menu: Open, Copy link, Duplicate, Close or Reopen (tier 1), Delete (tier 2, naming the responses that go with it).

Arabic: منشئ النماذج · نموذج جديد · مفتوح · مسودة · مغلق · من يمكنه تعبئته · أي شخص لديه الرابط.
