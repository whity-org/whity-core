# Mobile: create flows

From the Create sheet (M.11):

- **Scan a receipt:** the camera finds the receipt's edges and takes the photo by itself when it's steady; a photo or a PDF can be chosen instead. Flash at the top, shutter in the thumb zone.
- **Check what was read:** the Expense assistant fills the claim; each field says **Sure** or **Check** (yellow) so the person only looks at what needs it. Pick what it was for, add a note, **Send to Emad**.
- **Ask by voice:** hold the microphone; the words appear as they're heard, with a live waveform. **Let go to send, slide left to cancel.** The answer arrives in the Agents tab's chat.
- **A quick note:** a title and text, with a toolbar above the keyboard (heading, bold, bullets, to-do, photo, dictation, mention). An agent may offer to help as a dashed suggestion; nothing changes unless the person taps **Yes**.
