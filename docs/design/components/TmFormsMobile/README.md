# Mobile: forms and stock count

- **Forms:** what the person can fill in (chosen by their role), then **My requests** with where each one is: with Emad, approved, or returned with what to fix.
- **Filling:** one step per screen with the progress bar; a type as chips, dates, a computed line ("3 working days. You'll have 11 left this year."), an optional note. It saves as it goes, so a call or a locked phone loses nothing.
- **Check and send:** the answers as facts with **Change something**, where it goes next as steps, and **Send to Emad**.
- **Stock count:** the camera scans barcodes (or type the item); the item and how many were expected; a **72px stepper** with **+** as the main button on the thumb's side; "3 short"; **Skip** and **Next item** at the bottom. Tapping the number opens the keypad.

On the web: the form builder and responses (A34).
