# New agent: presets (AI.2)

The gallery **New agent** opens. Each preset card: icon, name, how many workspaces use it, one sentence on what it's for, three things it does, what it needs (an app such as Front Office, or "Works with Whity alone"), and **Use this agent**. **Start from blank** is the last card, dashed.

Using a preset opens the new agent's page with everything filled in, every action on Ask first, working for the person creating it. A preset needing an app that isn't installed says so and links to the store.

Arabic: اختر وكيلاً للبدء منه · استخدم هذا الوكيل · ابدأ من الصفر · يحتاج · يعمل مع Whity وحده.
