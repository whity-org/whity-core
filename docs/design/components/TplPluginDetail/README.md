# Plugin detail

Everything needed to decide whether to install a plugin, on one page.

- **Header:** the logo (64px), the name, the publisher (a link to its page), the trust mark and usage (S.4), the one-line purpose, what it adds, then **Install**, the one action on the plane, with the price and "billed on your Whity invoice" (S.2). People without `plugins:install` (S.3, S.9) see the button disabled with "Ask someone with permission to install plugins".
- **Tabs:** Overview, Permissions (with a count), Changelog, Support.
- **Overview:** screenshots drawn with real Whity components (so they look like the workspace they'll run in), a short description, and **What it adds** in three boxes: Screens, Document blocks (each marked Prints or Notes only, E.18), and Agent tools (dashed, like everything agents do), each tool with the mode it starts in.
- **Facts:** publisher and verification, how it runs (natively, or sandboxed, E.17), version and last update, languages, usage, billing, support. If it sends data outside the workspace, a warning box names the domain and what goes there. This is the one place a plugin's reach is spelled out before installing.
