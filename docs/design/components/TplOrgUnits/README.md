# Organisational units (A13)

- **Page:** Tree (default) or Chart, remembered per person. Each unit shows its member count; the selected unit is tinted.
- **Drawer** (P.1) for one unit: Add a unit inside and Move to… as buttons in its footer (A.2); ⋯ holds only Delete unit (tier 2, saying where its people go). Tabs: Members, Roles here (roles limited to this unit), Details (name, short code). Actions only appear for people with `ous:write`; the inventory found them shown to everyone.

Arabic: الوحدات التنظيمية · وحدة جديدة · شجرة · مخطط · الأعضاء · الأدوار هنا · نقل إلى.
