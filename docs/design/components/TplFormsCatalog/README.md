# Forms

The forms a person can fill in (the built Forms catalogue), as cards: drafts first under **Continue where you left off** (with the step reached), then all forms with where they go and how long they take. A form due today shows a warning badge. A card opens the form to fill (`TplFormFill`).

Empty: "No forms for you yet". Arabic: النماذج · تابع من حيث توقفت · كل النماذج · مستحق اليوم · يذهب إلى.
