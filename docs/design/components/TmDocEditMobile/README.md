# Mobile: documents, with light edits

**Read, comment, suggest, light edits** (DC.1):

- **Reading:** the document at 17px; highlighted text with a numbered pin opens its comment thread; **Suggest** and **Comment** (icon buttons with labels for screen readers) and **Sign** in the bottom bar.
- **Suggesting:** a green "Suggesting" chip; deletions struck in red, additions underlined in green; a toolbar above the keyboard for bold, lists, checklists, a comment, and the agent. The document's owner accepts or rejects.
- **Checklists:** tick items with 22px boxes (48px rows); ticks save as you go.
- **Asking an agent:** select a paragraph; the agent offers to make it clearer, add the Arabic, or tighten terms; its changes arrive as suggestions.

Tables, fields and templates stay simpler on the phone: they show and can be commented on; editing them is on the web (`TplDocDesigner`, section 18).
