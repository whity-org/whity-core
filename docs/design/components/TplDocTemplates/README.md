# Templates (A31)

- **Table:** Template (icon by kind, title, Whity starter or Converted badge, kind and record type in words), Status (Draft; Published, version N), **Who can see it** in a sentence, Changed. A row opens the template in the editor (section 18).
- **Row menu:** Open, Issue a document, Make a copy, Who can see it… (a dialog: tier, unit, extra permission, with a live sentence and a warning when it narrows access), Delete (tier 2).
- **New template** (main) starts blank, from a Whity starter, or from a copy.

Arabic: القوالب · قالب جديد · منشور، الإصدار · مسودة · من يمكنه رؤيته · قالب من Whity · ورقة ملصقات.
